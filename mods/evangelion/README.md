# Evangelion / NERV Operations

An original native Herdr layout inspired by the 1995 anime's command screens. Installed as `evangelion`; switch using any layout menu or Settings → Layouts. No server, browser or additional package is needed.

## Operations

- **Deployments** are Herdr spaces. Real names, machine labels and operation counts stay visible. Click to select; right-click for Herdr's space menu.
- **Operations** are tabs. Click to select; right-click for rename/close actions. `+` opens Herdr's agent and terminal launcher.
- **EVA units** are actual agents. Codex defaults to EVA-01, Claude to EVA-02, others to EVA-00. This is a cosmetic Herdr adaptation, not a canon pilot assignment. Every unit keeps its real title and terminal address. `DETAILS` selects a persistent livery for that address; click the unit to focus it.
- **MAGI** is a three-channel status display: MELCHIOR-1 counts working agents, BALTHASAR-2 counts completed agents, CASPER-3 counts agents needing input. Click a channel to filter the sidebar. These are status summaries, not three additional agents or an approval system.
- **Angel contacts** visualize blocked agents, always showing the real identity and `NEEDS YOU`. Their Ramiel/Sachiel emblems are narrative decoration, not diagnoses of malicious behavior.
- **MAGI** in the top bar hides/shows the right monitor, useful in narrow windows. Sidebar and monitor dividers resize. Pane headers provide split-right and zoom controls; right-click opens the actual pane menu.
- **EVANGELION ▾** in the bottom bar opens the native layout menu, deduplicates personal replacements and marks the active layout.
- **MOTION** disables decorative native pulses. No automatic sounds or interruptions. `?` opens the operations manual.

## Host status

The bottom bar reads this computer's network and battery with macOS `/usr/sbin/scutil --nwi` and `/usr/bin/pmset -g batt`, initially and every 30 seconds while the layout copy is alive. No outbound network probes or external files are used. Link availability is **not an Internet connectivity test**. Hover for interface names and last-update time. The battery icon shows percent and AC/charging state; desktops without an internal battery omit it. Failed probes show unknown. Other operating systems currently show unknown network status and no battery icon; there is no fabricated fallback. Remote machine availability is separately listed under UMBILICAL LINKS.

## Training and discoveries

Open **SIM** for two actual games:

1. **Ireul containment** — a 5×5 reversible lights puzzle. Each click toggles the cell and its four orthogonal neighbors. Clear all infected cells. Every board is generated by legal moves, so all are solvable. Undo, parity-based hints, restart and saved best scores are supported.
2. **Israfel synchronization** — reveal pairs in a 4×4 memory drill. Matching pairs stay exposed. Press CONTINUE after a mismatch; no fast timer forces a guess. Best attempt count is saved.

Easter eggs:

- Tap the NERV emblem **three times**, or the MAGI heading **seven times**, to open the SEELE archive. Its seven-eye monolith and CASPER refusal are cosmetic; no terminal operation runs.
- **REFRIGERATION / 02** opens Pen Pen's refrigerator. Open the door and ask `WARK?` for rotating off-duty messages.
- Win either game for the **CONGRATULATIONS / おめでとう** title card. Cleared exercises appear in the secret archive.

Games never send input to terminals or agents. Scores, motion preference and liveries use the `evangelion.*` shared-state namespace.

## Research and art

The design separates canonical references from the Herdr adaptations above:

- [Fontworks: Matisse EB and Evangelion](https://fontworks.co.jp/column/394/) — high-contrast display typography and condensed labels. The proprietary Matisse font is not bundled. Antonio (SIL OFL, included) handles technical labels; system Times/Hiragino fonts handle title-card accents.
- [MAGI imagery in the official Norton × Evangelion collaboration](https://japan.norton.com/evangelion_cp/) — the three labeled cores and orange/teal/red screen vocabulary.
- [Ireul, episode 13](https://wiki.evageeks.org/Ireul) — biological computer infiltration; inspiration for a logic game, not a recreation of the episode's actual software.
- [Israfel, episode 9](https://wiki.evageeks.org/Israfel) — synchronized EVA-01/EVA-02 combat; inspiration for the matching drill.
- [Ramiel](https://wiki.evageeks.org/Ramiel) — blue octahedral silhouette, not a generic hexagon.
- [EVA-01](https://wiki.evageeks.org/Evangelion_Unit-01) — horned head silhouette and test-type identity.

All SVG helmets, Angel emblems, penguin, leaf, monolith and preview are original vector drawings for this layout. No anime footage, soundtrack or commercial font files are included. The warm paper light appearance is an adaptation for legibility; dark is the command-screen look. Both appearances keep a dark terminal surface and readable ANSI colors because already-running agents can retain dark-mode formatting.

## Validation

Run `herdr-app check ~/.config/herdr-app/mods/evangelion`. It checks only the initial render. The build also checks isolated roles, populated agent/pane branches, both games and battery variants. Pure state tests cover puzzle solvability, undo invariants, hints, matching rules, network/battery parsing, layout names and livery/status mappings. Live checks and screenshots are recorded in `VALIDATION.md`.
